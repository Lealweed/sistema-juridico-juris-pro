## Template de Procuração

Coloque aqui o arquivo `procuracao_template.docx` com as seguintes tags entre chaves que serão substituídas automaticamente:

| Tag | Descrição |
|---|---|
| `{NOME}` | Nome completo do cliente |
| `{NACIONALIDADE}` | Nacionalidade (padrão: Brasileiro(a)) |
| `{ESTADO_CIVIL}` | Estado civil |
| `{PROFISSAO}` | Profissão |
| `{CPF}` | CPF do cliente |
| `{RG}` | RG do cliente |
| `{ENDERECO_COMPLETO}` | Endereço completo formatado |

### Como criar o template

1. Abra o Word e redija a procuração normalmente.
2. Onde houver dados variáveis do cliente, substitua pelo nome da tag (ex: `{NOME}`).
3. Salve como `.docx` com o nome `procuracao_template.docx` nesta pasta.
